# AI VIDEO STUDIO — استوديو الفيديو بالذكاء الاصطناعي

منصة عربية احترافية (RTL) لإنشاء الفيديوهات بالذكاء الاصطناعي، مبنية بواجهة حديثة تعمل أولًا على الهاتف،
مع نظام حسابات واشتراكات مدفوعة، ولوحة إدارة كاملة للمالك.

> **حالة التكامل مع مزوّدي الذكاء الاصطناعي:** لم يتم ربط أي مزوّد توليد فيديو أو صوت فعلي بعد.
> التطبيق يحفظ الطلبات، يطبّق الاشتراكات والحدود، ويعرض بوضوح حالة «غير متصل» في كل أداة.
> نقاط التكامل جاهزة على الخادم فقط، وستُفعَّل بإضافة متغيّرات البيئة الخاصة بكل مزوّد.

الأدوات الأربع:

1. **النص إلى فيديو** — وصف نصي ← مشهد سينمائي.
2. **الصورة إلى فيديو** — رابط صورة + وصف الحركة.
3. **التعليق الصوتي العربي** — نص عربي ← تعليق صوتي (نبرة وسرعة).
4. **إنشاء كرتون بالذكاء الاصطناعي** — وصف شخصية ومشهد كرتوني.

## التقنيات

- **الخادم:** Node.js 22 + Express 4، جلسات بكوكيز `httpOnly`، حماية CSRF، رؤوس أمان.
- **قاعدة البيانات:** SQLite عبر `better-sqlite3` (ملف واحد، بلا خدمة خارجية).
- **الواجهة:** React 18 + React Router 6 + Vite 6، تنسيق CSS مخصص (بلا مكتبات تصميم ثقيلة).
- **الاختبارات:** `node --test` — اختبارات تكامل حقيقية على الخادم وقاعدة بيانات مؤقتة.

## متغيّرات البيئة

| المتغيّر | الوصف |

| `SESSION_SECRET` | مفتاح توقيع الجلسات. إن لم يُضبط يُولَّد ويُخزَّن في قاعدة البيانات. |

| `OWNER_PASSWORD` | كلمة مرور المالك. إن لم تُضبط تُولَّد وتُطبَع في السجل مرة واحدة. |
| `TEXT_VIDEO_API_KEY` / `TEXT_VIDEO_API_URL` | مزوّد النص إلى فيديو (غير مربوط). |
| `IMAGE_VIDEO_API_KEY` / `IMAGE_VIDEO_API_URL` | مزوّد الصورة إلى فيديو (غير مربوط). |
| `VOICE_API_KEY` / `VOICE_API_URL` | مزوّد التعليق الصوتي العربي (غير مربوط). |
| `CARTOON_API_KEY` / `CARTOON_API_URL` | مزوّد الكرتون (غير مربوط). |

> المفاتيح تُقرأ داخل عملية الخادم فقط، ولا تُعاد في أي استجابة API، ولا تُبنى داخل حزمة الواجهة.
> استخدم `.env` محليًا أو إعدادات البيئة في منصة الاستضافة — لا تضع المفاتيح في Git.

### حساب المالك

عند أول تشغيل يُنشأ حساب المالك من `OWNER_EMAIL` و`OWNER_PASSWORD` بدور `owner` وحالة نشطة،
ويحصل على وصول غير محدود لكل الأدوات دون أي اشتراك. كلمة المرور تُخزَّن كتجزئة scrypt بملح فريد.

## نموذج الأمان

- **التحقق على الخادم:** كل مسار يتحقق من الجلسة والدور والاشتراك والحدود؛ لا يُقبل أي دور أو خطة من العميل.
- **الجلسات:** كوكي `httpOnly` + `SameSite=Lax` (+ `Secure` في الإنتاج)، وتُحذف عند تسجيل الخروج أو تعليق الحساب.
- **CSRF:** كل طلب معدِّل يتطلب رأس `X-Requested-With: ai-video-studio`، ومحتوى JSON عند وجود جسم للطلب.
- **كلمات المرور:** scrypt بملح فريد لكل مستخدم، وحد أدنى للطول، ورسائل خطأ لا تكشف وجود البريد.
- **حدّ المحاولات:** حدّ لعدد محاولات التسجيل/الدخول من نفس العنوان.
- **حساب المالك:** لا يمكن تعديل دوره أو تعليقه أو منحه اشتراكًا من واجهات الإدارة.
- **رؤوس الأمان:** `Content-Security-Policy`, `X-Frame-Options`, `Referrer-Policy`, `X-Content-Type-Options`.
- **عزل المشاريع:** لا يمكن لمستخدم قراءة أو حذف مشروع مستخدم آخر.

## بنية المشروع

```
server/
  index.js          # إنشاء التطبيق، رؤوس الأمان، CSRF، تقديم الواجهة
  db.js             # المخطط، الخطط الافتراضية، البيانات الأولية
  auth.js           # scrypt، الجلسات، حدّ المحاولات، تهيئة المالك
  entitlements.js   # مصدر الحقيقة للصلاحيات والحدود والاستخدام
  providers.js      # سجل الأدوات + عقود التكامل + كشف حالة الاتصال
  routes/           # auth · projects · admin
src/
  pages/            # Landing · Login · Register · Dashboard · ToolPage · History · Profile · Admin
  components/       # Layout · Icon · واجهة مشتركة
  api.js            # عميل fetch يضيف رأس الحماية
tests/api.test.js   # اختبارات تكامل الخادم
Dockerfile          # نشر متعدد المراحل، مستخدم غير جذري، مجلد /data
```

## النشر

```bash
docker build -t ai-video-studio .
docker run -p 3000:3000 \
  -e OWNER_EMAIL=owner@example.com \
  -e OWNER_PASSWORD='كلمة-مرور-قوية' \
  -e SESSION_SECRET='مفتاح-طويل-عشوائي' \
  -v ai_video_data:/data \
  ai-video-studio
```

- التطبيق يستمع على `0.0.0.0:3000`.
- قاعدة البيانات في `/data` — اربط مجلدًا دائمًا حتى لا تُفقد البيانات.
- اضبط `OWNER_PASSWORD` و`SESSION_SECRET` في الإنتاج، واستخدم HTTPS.

## الخطوات التالية (غير منفَّذة بعد)

1. ربط مزوّد فيديو حقيقي (Text/Image-to-Video) عبر عقد `submit`/`fetchStatus` في `server/providers.js`.
2. ربط مزوّد TTS عربي وتخزين الملفات الصوتية الناتجة.
3. استقبال نتائج المزوّد عبر Webhook مع التحقق من التوقيع وتحديث حالة المشروع.
4. بوابة دفع (Stripe/Tap/PayPal) لتفعيل الاشتراكات تلقائيًا بدلًا من الإدارة اليدوية.
5. معالجة الفيديو (مدة، مقاسات، ماء مائي) وتخزين دائم للمخرجات.
